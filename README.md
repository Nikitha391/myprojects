# ChefAI Reports Prototype

This is a lightweight front-end prototype for a ChefAI-style analytics hub. It includes:

- a hub screen with a report module
- a left navigation drawer triggered by the top-left waffle menu
- a report overview page with tabs for Recommended reports and My reports
- simple static interactions without a backend

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser.
